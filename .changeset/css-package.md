New package `@thomasfosterau/effect-css`: the CSS Syntax Level 3 tokenizer and parser (`Syntax.parseDeclarationList` for `style` attributes, `parseStylesheet`, `parseRuleList`, `parseRule`, `parseDeclaration`, `parseComponentValue`, `parseComponentValueList`) with recoverable, positioned `SyntaxError`s; `Color`, CSS Color 4 `<color>` parsing (named, hex, `rgb()`, `hsl()`, `hwb()`, `lab()`, `lch()`, `oklab()`, `oklch()`, `color()`), serialisation and conversion to sRGB; and `Length`, CSS Values 4 lengths with absolute-unit conversion. Checked against the css-parsing-tests suite.
